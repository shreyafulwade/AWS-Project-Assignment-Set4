# AWS Project Assignment – Set 4

This repository contains the implementation and documentation of three AWS projects completed as part of the AWS Project Assignment – Set 4.

## Projects Overview

### Project 1 – AWS CloudWatch Monitoring with SNS

This project focuses on monitoring an EC2 instance using Amazon CloudWatch.

The project includes:

- Monitoring EC2 CPU utilization
- Monitoring EC2 instance health
- Creating a CloudWatch alarm for high CPU usage
- Creating an Amazon SNS topic
- Configuring email notifications for alarm alerts

**AWS Services Used:**  
Amazon EC2, Amazon CloudWatch, Amazon SNS

---

### Project 2 – S3 and Lambda Event-Driven Solution

This project demonstrates an event-driven architecture using Amazon S3 and AWS Lambda.

The project includes:

- Creating an S3 bucket
- Uploading files to the S3 bucket
- Creating an AWS Lambda function
- Connecting S3 with Lambda
- Triggering Lambda when a file is uploaded
- Recording bucket and object details in CloudWatch Logs

**AWS Services Used:**  
Amazon S3, AWS Lambda, Amazon CloudWatch Logs

---

### Project 3 – Secure AWS VPC with Public and Private Subnets

This project focuses on designing a secure AWS VPC with public and private subnets.

The project includes:

- Creating an AWS VPC
- Creating public and private subnets
- Deploying an EC2 instance in each subnet
- Configuring an Internet Gateway
- Configuring a NAT Gateway
- Configuring public and private route tables
- Testing connectivity and security behavior

**AWS Services Used:**  
Amazon VPC, Amazon EC2, Internet Gateway, NAT Gateway, Route Tables
